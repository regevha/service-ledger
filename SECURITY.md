# Security policy

ServiceLedger is a private, internal tool. It is not offered as a supported product.

## Reporting a problem

Please do not open a public issue for a security problem. Report it privately to the
repository owner (use GitHub's "Report a vulnerability" under the Security tab, or contact
the owner directly). Include what you found, how to reproduce it, and what it affects.

## Things that must never be committed

- Customer, vendor or technician data, including real serial numbers and work-order numbers
- API keys, the shared password, or any other secret
