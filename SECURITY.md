# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue or pull request.

1. Open this repository's **Security** tab on GitHub.
2. Choose **Report a vulnerability** and fill in the form.

Include what you found, how to reproduce it, and what it could affect. Do not
include real passwords, API keys or customer data in the report.

The report is visible only to the repository maintainers until a fix is ready.
