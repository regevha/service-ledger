# SL-72 hand-off: admin screens fit a phone width

**Why:** at 390 px the corrections table on the reading-accuracy page was clipped on the right. The phone rule set `.admin-screen` to one `1fr` column; that column cannot shrink below its widest content, so the admin area grew to 492 px.

**Built:** `grid-template-columns: minmax(0, 1fr)` in the phone rule. The table's own wrapper (`.trend-table-wrap`, `overflow-x: auto`) now scrolls. CSS only.

**Checks:** looked at `#/admin/accuracy` at 390 px (see the PR).
