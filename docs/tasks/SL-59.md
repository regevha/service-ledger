# SL-59: several PDFs on the New report screen

Built
- Choosing or dropping two or more PDFs on New report opens the batch screen with those files, as a drop on Home does. Nothing is read until the person starts it.
- One PDF, or one or more photos, keeps the single-report flow. One PDF plus photos is refused; the message now ends "To upload several reports, choose only PDFs."
- The drop zone shows "Several PDFs? Each becomes its own report." The old link now reads "Have a pile of PDFs? Drop them all here, or open the several-files screen." (data-testid="open-batch" kept). The main drop-zone line is unchanged (an existing spec checks it).

Interface
- `chooseIntakeRoute(files)` and `isPdfFile` in `frontend/src/uploadFiles.ts` return `single`, `batch` or `problem`. `dropProblem` is unchanged apart from the mix message.
- `IntakeFlow` and `IntakeScreen` take `onBatchFiles(files)`. App.tsx has one `openBatchWith(files)` used by Home and New report.
- The 30-file limit and file-type notes stay in BatchIntake.
