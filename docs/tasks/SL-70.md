# SL-70 hand-off: free text measured on its own, re-read baseline saved and shown

**Why:** the first real re-read (9 reports, 40 fields) gave 67.5% kept. Structured fields were about 89%; the narrative `work_performed` matched 1 of 9 times because an exact match counts every rewording as a miss.

**Built:**
- `services/read_compare.py`: one rule, `same_value(field, read, kept)`, used by the accuracy page, the Home tile and `scripts/reread_baseline.py`. Exact for every field, except the free-text fields named in `FREE_TEXT_FIELDS` (`work_performed`, `fault_description`, `root_cause`, `service_description`), which ignore case, spacing and punctuation and nothing else (a changed number, word or word order still counts; tests in `test_read_compare.py`). By field name, not field type: a serial number is also "text" and stays exact. Home and page still agree for the same window (test).
- `GET /analytics/read-accuracy` adds `by_kind` (structured, free text) and `from_reread` (reports whose first reading is a re-read).
- The page shows the total (as before, equal to Home), numbers/choices/parts with the 99% goal, and written descriptions on their own, plus a note when some reports come from a re-read.
- `python -m scripts.reread_baseline --run --save`: stores each re-read as `original_fields` of a finalized report that has none (never replaces one; one transaction per report) and adds an extract job row with `params` = `{"baseline": "reread", prompt_hash, model}` and the field confidences, so the confidence bands and prompt table include these reports. Refused unless `USE_LIVE_CLAUDE=true` (a stub reading is invented). Without `--save` nothing is stored and the run says so.

**The figures move:** because free text is now compared loosely, the total on the page and on Home can be higher than before for the same reports. That is the intent (a retyped sentence is not a miss), not a data change.

**Use (from `backend/`):** `USE_LIVE_CLAUDE=true python -m scripts.reread_baseline --run --save --limit 9`, then open Admin > Reading accuracy.

**Checks (2026-11-14):** backend 1383 passed, 11 xfailed, coverage 95.58%; ruff clean; mypy 75 (baseline 75); `tsc -b` clean; Vitest 61 passed; no migration. Playwright runs in CI (`read-accuracy.spec.ts` asserts the two new tiles).
