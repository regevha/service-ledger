# SL-74 hand-off: the daily cap counts model jobs only

**Built (reliability review F2):**
- `_run_translate_job` marks a job `params.model_called = false` when it finished without the model: live mode, no explicit pages, and a readable text layer that is not Hebrew (the same case `translate()` answers with no call).
- `job_limits._counted` leaves those jobs out of both the daily cap and the failed-attempt count. Pending and running jobs still count (they may call the model), and so does every job without the marker. The limit (`DAILY_JOB_CAP`, 60) is unchanged.
- A scan without a text layer is not marked: its small language check is a model call.
