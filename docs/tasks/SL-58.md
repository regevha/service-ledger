# SL-58 hand-off: design system export

- `docs/design-system/` holds the ServiceLedger design system exported from the claude.ai Design System artifact "ServiceLedger": the rules (README.md), the tokens (tokens.json), the component preview styles (components.css, not loaded by the app) and `check_tokens.py`.
- The app stays the source of truth. Run `python3 docs/design-system/check_tokens.py` after changing a colour in `frontend/src/index.css`; it compares the first `:root` block and `:root[data-theme='dark']` (not the duplicate `prefers-color-scheme` block, and not spacing, radius, type, shadows or fonts). It is not in CI yet (#318, deferred).
- `tokens.json` already has SL-57's light `input-border` (#7d889f), so this PR merges after #307. On a tree without SL-57 the check reports that one token.
- Review fixes: the README no longer claims 16px phone inputs or a 15px body size (`--text-base` is unused; body text inherits 16px, controls set their own rem sizes), says dates follow the browser's locale, and lists what the check skips. `components.css` drops `.sl-btn:disabled` and the `.sl-field` background, which the app does not have, and adds the danger pressed and disabled states and the pill's capitalisation.
- Not exported: fonts (npm packages), the artifact's preview pages and its own metadata.
