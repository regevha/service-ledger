# SL-79 hand-off: first-run sample report (A and B)

Brief: `docs/features/first-run-sample/PRODUCT.md`. Built by the lead, directly.

## What was built
- **Data:** migration `0017_sample_flag` adds `is_sample` (default false) to `reports`, `instruments`, `instrument_models` and `places`. Reversible; downgrade deletes sample rows first. **Renumber at merge** (0017 is also used by PR #305).
- **Service** `backend/app/services/samples.py`: `create_sample` (demo institute + room, flagged model record, demo instrument `DEMO-0001`, an `extracted` report, a generated one-page synthetic scan, a succeeded classify job and a succeeded extract job holding the stored confidences), `remove_sample_data` (everything flagged, plus the scan folder), `stored_confidences`. Nothing is created at startup or by a seed (AC-05).
- **API:** `POST /sample-report` (201 first time, 200 after; returns `SampleReportOut` = ReportOut + `field_confidences`; 409 if the repair template is missing), `DELETE /sample-report` (204 always). `ReportOut.is_sample`. Finalize, classify and extract answer 409 for a sample.
- **Exclusions (AC-03):** report filters (list, search, export, repair counts), duplicates (both checks), Home figures, read-accuracy, maintenance, analytics unit lists and places, instrument / model / place lists and counts, the classifier's fleet, the Ask box's name lists, template usage counts. Deleting a template used only by the sample is allowed and removes the sample.
- **Frontend:** `Try with a sample report` under the upload box on New report, shown only when `GET /reports?status=finalized` has total 0. It opens the sample straight on the review step with the stored flags. Banner "Sample report. Not part of your ledger." with Delete. No Save and no Finalize buttons for a sample (`onSave` is now optional on ReviewScreen). Never labelled "placeholder", whatever the server mode.
- **Sample content:** invented repair form (Demo Maker, Demo Sorter D1, `DEMO-0001`, 12 March 2026). One read field is flagged (Root cause, 0.58); the review screen also flags Fault category, which a person fills in on every repair report, so it opens with "2 fields need attention".

## Decision that changed from the proposal
The sample is **synthetic**, not a BD scan (owner, 2026-11-20): the BD Test Set was not reachable from this repo and it is public. A real redacted scan can replace `_sample_pdf()` and the constants later.
