ServiceLedger WIP update

We’re making it easier to upload several reports, find and review them, and see where automatic classification needs a person’s input.

Published for review as WIP. GitHub points to commit 71919f9 on nir/wip-product-20261118. The snapshot has not been merged or deployed. Repository handoff

What’s on the published branch

  • Upload several PDFs from New report. Files enter a queue on the same screen. Add more files there, keep the optional technician value, and start reading the batch. Each PDF becomes a separate report.
  • Home and report filters. Home makes upload and the review queue clearer and distinguishes an instrument loading error from an empty maintenance list. Reports shows which filters are active and lets you clear them from the collapsed controls.
  • Dates and review fields. Review and filters accept day-first dates, and related screens show DD/MM/YYYY. The API still uses ISO dates. One review field now displays as plain text when read-only.
  • Classification accuracy. A report can retain the model’s classification attempts. The accuracy screen separates automatic classifications that were kept, cases needing attention, and reports without a recorded decision. Extraction edits are counted separately.
  • Labor-hours comparison. Instrument comparisons use the same parsing as fleet analytics, including decimal commas and alternate field names. Which report types qualify remains unchanged.
