One box to search, filter and summarize

The person types a question in plain words. The app shows how it understood the question as ordinary filter chips, so the answer is checkable and every chip can be edited or removed.

  • Understood as turns the sentence into the same filters as the Reports screen. No hidden logic.
  • Why it matched quotes the value or text that made each report a hit.
  • Summarize answers across the matches and lists the reports it used.
  • Ask by voice: tap the microphone, say the question, tap stop. It is turned into text in the same box, so the chips show what was heard and understood. Recording is simulated in this mockup.

A home page that answers “what needs me today?”

For a core facility manager the useful first screen is a short to-do list, not a menu. It puts the work waiting on you first, the maintenance that is due next, and a place to drop new reports. It also holds the AI search box, so it is the one place to start.

  • Needs your attention: reports to review, jobs waiting for a classification choice, failed reads.
  • Maintenance due: overdue first, then the next 30 days, taken from the instrument records.
  • Drop area: drag in one or many PDFs from anywhere on this page.
  • Analytics stays its own tab; the home page only carries four numbers.

Laid out for a small laptop

Small laptops give about 1280 × 580 px once the browser toolbar is counted, and every row of header takes space away from the work. The frame below is drawn at true size and scaled to fit this page, and it rearranges at each width.

The frame height is the visible area after a typical browser toolbar and tab strip. The grey well is the scan; it never needs more than a third of the width.

Tighter top bar48 px instead of 56. Tab text shrinks, then becomes icons at 1200 px and below.

Several PDFs in, one confirmation at a time

Dropping many files starts one queue. Each file is read and classified on its own, and the person confirms them one by one or approves all the confident ones together. Extraction then runs in the background and each report lands in the review list.

  • Confident files can be approved together; unclear ones wait for a choice and never block the rest.
  • Duplicates are caught before any money is spent on reading them.
  • Click a file in the queue, then Confirm & next.

Filters that start small and grow

Eight dropdowns in a row hide what is actually applied. This version shows only the filters in use, as chips. A chip opens a short checklist, “Add filter” brings in the rest, and the count updates as you tick.

  • Try it: click a chip, tick another model, then use “Add filter” for Status.
  • Saved filters and quick presets sit on the same line, so common views are one click.
  • Analytics can reuse this bar as it is today.

Review before sharing between institutes

Reports will travel between institutes, so removing names and personal details has to be reliable. Extraction marks every person name, signature, email and phone number. A person approves the redactions once, then the shared copy contains only the redacted text.
